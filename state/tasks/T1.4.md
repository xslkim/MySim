## 本任务新踩的坑(供 AGENTS.md 候选)

1. TUNA 装 stable_baselines3 把 torch 顶成 2.13.0+cu13(已知坑的又一实例)——恢复:降 torch 后须 `pip uninstall` 全部 nvidia-*-cu13,再 `--force-reinstall --no-deps` 全部 nvidia-*-cu12;若 torch import 报 libnvshmem_host.so.3 缺失=2.13 文件残留,须删 site-packages/torch* 后重装
2. opencv-python 与 opencv-python-headless 共用 cv2/ 目录,卸载其一即带走 cv2——nuscenes-devkit/lyft_dataset_sdk 会拖 GUI 版入 env,卸 GUI 版后必须 `--force-reinstall --no-deps opencv-python-headless==4.10.0.84`
3. lyft_dataset_sdk 会把 numpy 顶到 2.x——任何补装命令都要带上 `numpy==1.23.5`(和 `torch==2.7.1`)一起钉
4. `CUDA_VISIBLE_DEVICES=""` 下 transformers 的 is_flash_attn_2_available()→torch.cuda.is_available() 在 WSL2 双 free 崩(driver 577.00+cu128)——CPU 验证不要屏蔽卡,不分配即可
5. hf-mirror 单连接 ~1MB/s,`HF_ENDPOINT=https://hf-mirror.com HF_HUB_ENABLE_HF_TRANSFER=1` 多线程 ~40MB/s
6. (2026-08-29 GPU 冒烟)vendored `auto_fp16`(mmcv/utils/fp16_utils.py)不只是 cast 输入——内部还套了 `torch.cuda.amp.autocast(enabled=True)`,因此 `fp32_infer=True` + `custom_wrap_fp16_model` 时 EVA 背骨 conv/linear 被 autocast 桥成 fp16 计算、权重仍 fp32,flash_attn 的 fp16/bf16 assert 不会触发;**fp32 官方路径即工作路径,无需 fp16_infer 回退**。另:规划 VLM 两次调用均为单次前向无自回归(llava_qwen.py `inference_action_distribution`/`inference_waypoints` 忽略 max_new_tokens),单帧 0.34s 是真实成本不是假象;`torch.load(mmap=True)` + `load_state_dict(strict=False)` 替代 mmcv `load_checkpoint` 可避免 29.5GB ckpt 在 32GB WSL RAM 下全量驻留
