### 2026-08-30 诊断 agent(低分根因:已坐实+已修复+已验证)

**根因(一句话)**:官方 release ckpt 早于代码改名——BEV 特征投影层在 ckpt 里叫 `transfuser_proj.{weight,bias}`、代码里叫 `bev_encoder_proj.{weight,bias}`(形状完全一致 [2560,1512]/[2560]),流式 loader 按名匹配导致该层**保持随机初始化**,每帧拼接进 LLM 序列的 64 个 BEV token(LiDAR+RGB 几何,承载障碍规避能力)全是垃圾 → 模型直冲撞车、满油门顶死障碍物 → TickRuntime/AgentBlocked,18 路线 meanDS 27.5 vs 官方 87.34。

**证据链**:
1. eval log 装载段:`Streamed 1154 tensors`(2302 总 − 1146 bev_encoder.* − 2 transfuser_proj),`2 missing(bev_encoder_proj.*)/2 unexpected(transfuser_proj.*)`;BEV backbone 1146 keys 单独提取 strict 加载无警告(106.5M 参数全冻结)——**全模型唯一随机层就是 bev_encoder_proj**。

## 接线方案(对接 Windows 原生 UE4 server,对齐 run_eval_ue4.sh)

**结论:用 vendored leaderboard + 移植 2 个已验证补丁**;不混用 b2d leaderboard(agent 会把自带 leaderboard 插到 sys.path[0],混用有类身份/路径双源风险,虽当前 diff 琐碎但不值得)。

需移植的补丁(b2d 侧 external/bench2drive 均已实战):
1. **B2D_EXTERNAL_SERVER=1 分支**(b2d leaderboard_evaluator.py:~201-212):跳过 CarlaUE4.sh 自起 + find_free_port 改端口,直连 args.host:args.port。vendored 版自起逻辑在 ~203-230(含 CARLA_ROOT 自动探测),照抄替换即可。
2. **pkg_resources → importlib.metadata**(b2d 同款 4 行:import + get_distribution("carla") 两处,evaluator:21/115;scenario_runner/scenario_runner.py:44 同款,非评测路径可顺手)。**或**不改代码、env 钉 `setuptools==80.9.0`(现为 83.0.0 已无 pkg_resources;wandb 0.25.1 不受影响)。

启动命令范式(评测 agent 据此写 tools/run_eval_automot_ue4.sh,骨架复用 tools/run_eval_ue4.sh 的 server 自愈 while 循环 + t11_ensure_server.py ue4):

```bash
ROOT=/home/xsl/MySim; AM=$ROOT/external/AutoMoT
export PYTHONPATH=/home/xsl/carla0915-pythonapi:/home/xsl/carla0915-pythonapi/carla:\
$AM/leaderboard:$AM/leaderboard/team_code:$AM/scenario_runner:$AM/Automot:$AM/Automot/mot

  $AM/leaderboard/leaderboard/leaderboard_evaluator.py \
```

## 兼容风险 / 渲染结论注意

- **动作分支含 LiDAR 通道**(AGENTS.md 已立案):agent sensors() 自报 `sensor.lidar.ray_cast`(x0 y0 z2.5 yaw-90,id=LIDAR)——harness 按 agent 声明挂传感器,**无需外部传感器配置**;评测时确认 route 用 SENSORS track 即可。动作输入 = LiDAR BEV histogram + BEV encoder(RGB+LiDAR)特征;另有俯视 bev RGB 相机(512² fov50@z50)仅供 viz/render。CAM_FRONT 1024×512 fov110 是 VLM 唯一前视视觉输入。**UE4vsUE5 渲染结论须注明 LiDAR 稀释。**
- `--resume` type=bool 坑 vendored 版同样在(evaluator:566);且官方 run_evaluation.sh **恒传 --resume=${RESUME}(默认"False")→ 恒为 True** —— 自写接线脚本时该参数首轮整个省略(同 run_eval_ue4.sh 头注)。
- srunner/tools/{scenario_parser,route_parser}.py 仍有 getchildren()(b2d 已补,vendored 未补),但**不在评测 import 链**(leaderboard route_scenario 用 leaderboard.utils.route_parser,已自带 list() 修复)——冒烟已验证全链 import 无此雷;若未来走 scenario_runner.py 主入口才需补。
